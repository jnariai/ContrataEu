## Brazilian Portuguese conventions
- Same one-page, single-column rules. Don't add data sometimes seen in Brazilian CVs that hurts tech applications: CPF/RG, age, marital status, full address, photo.
- Cover letter: 150–300 words; open with “Olá, equipe de {empresa}” or the recruiter's name if known; neutral, professional tone; never “Prezados Senhores”.
- Recruiter message: LinkedIn style, short, “Olá, {nome}!” opener, using “você”.
